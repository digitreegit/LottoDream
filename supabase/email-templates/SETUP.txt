Lotto Dream — Supabase 비밀번호 재설정 이메일 적용 방법
============================================================

(2) 이메일 본문 HTML
--------------------
1. Supabase Dashboard → Authentication → Email Templates
2. "Reset password" 템플릿 선택
3. 이 폴더의 recovery.html 파일을 열어 **전체 내용**을 복사한 뒤, 대시보드의 본문(HTML) 편집창에 붙여넣기
4. Subject(제목) 예시 (원하는 문구로 변경 가능):
   - Reset your Lotto Dream password
   - 또는: Lotto Dream — Reset your password
5. Save

※ 본문은 Supabase Go 템플릿 변수를 사용합니다: {{ .ConfirmationURL }}, {{ .Email }}
   (스팸 검사 완화를 위해 {{ .SiteURL }} 링크는 넣지 않았습니다. 필요하면 한 줄 추가 가능.)

저장 시 "Contains blocked keywords" / 스팸 검사 오류가 나는 경우
----------------------------------------------------------
대시보드(내장 이메일)는 SpamAssassin 등으로 본문을 검사합니다. 표·숨김 프리헤더·
동일 링크 반복·특정 안내 문구가 점수를 올릴 수 있어, recovery.html 은 가능한 한
짧은 HTML로 맞춰 두었습니다.

그래도 저장이 안 되면:
- Custom SMTP 를 켜면 같은 문구로도 저장·발송이 가능한 경우가 많습니다(안내 메시지에 나온 대안).
- 제목(Subject)도 기본 "Reset Your Password" 로 두고 본문만 바꿔 저장해 보세요.


(1) 발신자 표시 이름 "Lotto Dream"
----------------------------------
기본 Supabase 발송 주소(noreply@mail.app.supabase.io)를 쓰는 경우,
받은편지함에 "Supabase Auth"처럼 보이는 것은 **호스팅 측 발신 정책** 때문이며,
표시 이름만 바꾸는 옵션이 제한될 수 있습니다.

**보내는 사람 이름을 "Lotto Dream"으로 확실히 맞추려면:**
- Dashboard → Project Settings → Authentication → SMTP Settings
- Custom SMTP(예: Resend, SendGrid, Amazon SES 등)를 연결
- Sender / From name 필드에 **Lotto Dream** 입력
- From email은 해당 SMTP에서 허용한 도메인 주소 사용 (예: noreply@yourdomain.com)

로컬 Supabase CLI로 개발하는 경우 config.toml에서 recovery 템플릿 경로를 지정할 수 있습니다.
자세한 내용: https://supabase.com/docs/guides/auth/auth-email-templates
